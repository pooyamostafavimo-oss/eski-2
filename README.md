# ربات گلچین اخبار

## چطور کار می‌کنه
هر ساعت (قابل تغییر) اجرا میشه، پیام‌های جدید چنل‌های منبع رو می‌خونه — **متن، عکس، و ویدیو** — هرکدوم رو (روی متن/کپشنش) به Gemini میده تا توی یکی از این دسته‌ها بذاره: **جنگی، خنده‌دار، رندوم، مهم، عجیب** (یا هیچکدوم = رد میشه)، و اگه توی یکی از این دسته‌ها بود خودش تصمیم می‌گیره عیناً کپی کنه یا بازنویسی/خلاصه کنه — بدون ذکر منبع — و پست می‌کنه توی چنل خودت، همراه با عکس/ویدیوش اگه داشته باشه.

چنل‌های منبع پیش‌فرض: Newz021، withyashar، pm_afshaa، IranianMinds، hutt_news، BadCandom، FUTBALLI18، drtel، nikotiinn_text، nabe_saman، Tala_Dollar_ir، SoccerrWorld

⚠️ نکته درباره‌ی مدیا: چون خود اکانت تلگرام تو (نه یه بات جدا) پست می‌کنه، دیگه لازم نیست بات جدا بسازی — کافیه همون اکانت روی چنل مقصد ادمین یا حداقل عضو با اجازه‌ی پست باشه.

## چیزایی که اضافه‌تر از درخواست اولیه اضافه شد
- **چند کلید Gemini با چرخش خودکار** — اگه یه کلید به سقفش خورد (خطای ۴۲۹)، خودش میره سراغ کلید بعدی
- **جلوگیری از پست تکراری** — هش متن نهایی هر پست نگه داشته میشه؛ اگه همون خبر از یه چنل دیگه هم اومد، دوباره پست نمیشه
- **پشتیبانی از آلبوم** — اگه یه پست چندتا عکس/ویدیو با هم داره، همه‌شون با هم و با یه کپشن پست میشن
- **مدیریت FloodWait** — اگه تلگرام موقتاً محدودت کرد، خودش صبر می‌کنه و دوباره تلاش می‌کنه، به‌جای اینکه کل اجرا fail بشه
- **تأخیر بین درخواست‌های Gemini** — پیش‌فرض ۴ ثانیه، که به سقف RPM نخوریم

## مراحل راه‌اندازی

### ۱. ساخت Session String (برای خوندن چنل‌های دیگه)
چون بات معمولی نمی‌تونه پیام چنل‌هایی که ادمینشون نیستی رو بخونه، باید با اکانت خودت (یوزراکانت) وارد بشی. این کار **فقط یک‌بار** و **لوکال روی سیستم خودت** انجام میشه (نه توی GitHub Actions):

```bash
pip install telethon
python3 -c "
from telethon.sync import TelegramClient
from telethon.sessions import StringSession
api_id = 123456        # از https://my.telegram.org
api_hash = 'abcdef...' # از https://my.telegram.org
with TelegramClient(StringSession(), api_id, api_hash) as client:
    print(client.session.save())
"
```

بهت کد تایید تلگرام و رمز دومرحله‌ای (اگه داری) رو می‌پرسه، و در آخر یه رشته طولانی چاپ می‌کنه — همون `TG_SESSION_STRING` هست.

⚠️ این رشته معادل رمز عبور اکانتته؛ جایی جز GitHub Secrets ذخیره‌ش نکن.

### ۲. ساخت چنل مقصد و دسترسی پست
دیگه لازم نیست بات جدا با @BotFather بسازی — چون همون اکانت یوزری که توی مرحله ۱ session گرفتیم مستقیم پست می‌کنه (چون برای عکس/ویدیو، کپی مستقیم روی سرورهای تلگرام سریع‌تر و بی‌دردسرتره). فقط مطمئن شو همون اکانت تلگرامت روی چنل مقصد (`TARGET_CHANNEL`) ادمینه یا حداقل اجازه‌ی پست داره.

### ۳. گرفتن Gemini API Key (چندتا)
از https://aistudio.google.com/apikey — با هر اکانت گوگل جدا می‌تونی یه کلید بگیری. با ۱۲ چنل منبع و چک هر ساعت، **۲ تا ۳ کلید** کافیه (خصوصاً برای اجرای اول که باید عقب‌افتادگی زیادی رو جبران کنه). اگه بعداً دیدی هنوز کم میاره، یکی دیگه اضافه کن.

### ۴. تنظیم Secrets در GitHub
Settings → Secrets and variables → Actions → New repository secret:

| Secret | مقدار |
|---|---|
| `TG_API_ID` | از my.telegram.org |
| `TG_API_HASH` | از my.telegram.org |
| `TG_SESSION_STRING` | همون رشته مرحله ۱ |
| `TARGET_CHANNEL` | یوزرنیم چنل خودت، مثلاً `@my_channel` |
| `GEMINI_API_KEYS` | کلیدهای Gemini، با کاما جدا: `key1,key2,key3` |
| `SOURCE_CHANNELS` | اختیاری — چنل‌های پیش‌فرض همین الان توی کد ست شدن. اگه خواستی عوض کنی، با کاما جدا بنویس |

### ۵. آپلود در ریپو و فعال‌سازی
این پوشه رو push کن به یه ریپوی گیت‌هاب (می‌تونه private باشه). فایل ورک‌فلو (`.github/workflows/curator.yml`) خودکار هر ساعت اجرا میشه. برای تست فوری، از تب Actions روی ریپو، "Run workflow" رو بزن (workflow_dispatch).

## تنظیمات قابل تغییر
- تناوب اجرا: خط `cron` توی `curator.yml`
- تعداد پیام حداکثر هر چنل در هر اجرا: `MAX_MESSAGES_PER_CHANNEL`
- مدل Gemini: `GEMINI_MODEL` (پیش‌فرض `gemini-2.0-flash`)
- تأخیر بین درخواست‌های Gemini: `GEMINI_CALL_DELAY_SECONDS` (پیش‌فرض ۴ ثانیه)
- تعداد هش‌های ذخیره‌شده برای تشخیص تکراری: `MAX_DEDUP_HASHES` (پیش‌فرض ۵۰۰)
